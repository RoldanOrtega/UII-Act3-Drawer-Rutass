## Mi Prompt
"Hazme una app en Flutter que se llame Lecturas. Quiero que el fondo de toda la app sea negro mate y que combine con blanco y tonos de rosa que estén bonitos (un rosa pastel y uno más fuerte para resaltar).La estructura debe ser así: El Drawer (Menú):
El encabezado tiene que ser rosa fuerte. Quiero que la imagen circular del negocio esté al lado del nombre 'Lecturas' (en la misma línea), no abajo. La información (dirección, teléfono y correo) debe aparecer abajo por puntos, bien ordenada. El resto del menú debe ser rosa claro y las letras de las categorías con sus iconos en color negro. Pon estas opciones: Inicio, Romance, Acción, Comedia, Suspenso.

En todas las páginas (incluyendo las categorías) se debe ver la hamburguesa, pero no la típica, sino un icono de libro abierto en color negro. No quiero que salga la flecha de regresar; quiero poder abrir el menú desde cualquier parte. La barra de arriba (AppBar) debe ser rosa claro y el título 'LECTURAS' en negro. Las Páginas: Todas las páginas, incluyendo la de Inicio, deben tener una imagen centrada de 200x200 que venga desde un link de GitHub. La imagen debe tener un marco rosa con bordes redondeados para que se vea bien estética.

Separa todo por archivos. El main.dart con las rutas nombradas, una carpeta que se llame LasPaginas para el inicio y otra carpeta que se llame categorias donde esté el diseño de cada una."
